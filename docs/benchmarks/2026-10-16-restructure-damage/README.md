## Exact change

`dfi_get_damage` (`src/combat/turn.c@dc9ce14b`, lines 1095–1760, 666 lines) is cut into six static phase functions in
`src/combat/mechanics/damage/` (the folder of the plan's target structure). The headers are included by `turn.c` where
the function stood (lines 1095–1100), so the translation unit, its dependencies and the damage order are unchanged. The
orchestrator `dfi_get_damage` stays in `turn.c` (now lines 1102–1183): the fixed-damage callbacks (Final Gambit, Super
Fang, Endeavor, OHKO, Night Shade), the six phase calls and the final damage.

- **Every line is unchanged and in order.** [verify_lines.py](verify_lines.py) checks it mechanically: each old range
  is contiguous in its header, the head and tail are in `turn.c`, `crit_mult` (its only reader is the crit phase) is in
  `crit.h`, and `turn.c` outside the function is byte-equal. A phase adds only a prologue that loads its inputs from the
  context and an epilogue that stores its outputs; the orchestrator adds the context and six `if (st != DUOFORGE_OK)
  return st;` hand-offs (each phase's early returns are the old ones).
- **Stack context** `dfi_damage_ctx` (`context.h`): 14 fields, 64 bytes on LP64, a local of `dfi_get_damage`, never on
  the heap.
- **Forced inlining:** `DFI_ALWAYS_INLINE` in the new private header `src/core/inline.h` (GCC/Clang
  `inline __attribute__((always_inline))`, MSVC/clang-cl `__forceinline`, otherwise `inline`). Not in `include/`.
- No renames, no cleanups, no new public number, no heap, no test or generated byte changes. Decision 0015 and the other
  docs name `turn.c` / `dfi_get_damage`, which stays true (the orchestrator keeps the name); frozen research artifacts keep
  their old line references.

   about 11 % of 2^31. The refusal itself is covered by `tests/mechanics/test_modifier.c:111`.

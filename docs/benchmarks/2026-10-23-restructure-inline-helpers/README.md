## Change

The move-body cut (#635) left small helpers out of line: GCC's per-caller inline limits on the one very large body
([its README](../2026-10-17-restructure-move-body/README.md)), callgrind +0.44 % with IPO / +0.26 % without. They become
`DFI_ALWAYS_INLINE` (`src/core/inline.h`):

| Helper | File |
|---|---|
| `dfi_pos`, `dfi_at` | `src/combat/run_internal.h` |
| `dfi_item_code`, `dfi_holds` | `src/combat/items/held.h` |
| `dfi_ability_code`, `dfi_ability` | `src/combat/abilities/current.h` |
| `dfi_has_type`, `dfi_alive` | `src/combat/turn.c` |

All of them are `static`. They were never exported, so the export list is unchanged, and #629's `extern` definition and link
test are not needed. Nothing else changes.

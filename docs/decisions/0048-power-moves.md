# 0048 - The power moves (G86): Heavy Slam, Hard Press, Ice Spinner, Belly Drum; Body Slam, Razor Shell, Tickle

Status: **proposed** (H23, lane A batch 6, step 5cn). The lead approved the design of phase 1 and phase 2 (answers of 2026-10-10: no new public value; Tickle in the G57 list, one entry; `-setboost` read as the BOOST event of the change, option (a)). The evidence section is filled in before the report.

## Problem

Seven moves of batch 6 (decision 0015 letter 5cn). Three of them need no handler: Body Slam (a 30 percent paralysis secondary), Razor Shell (a 50 percent Defense drop secondary, slicing) and Tickle (Attack and Defense -1, reflectable). Four need a rule that the generic columns cannot hold: Heavy Slam (the base power from the weight ratio of the two Pokemon), Hard Press (the base power from the target's current HP), Ice Spinner (the terrain ends after a hit) and Belly Drum (half the maximum HP for +6 Attack, a refusal at half HP or at +6).

## The pin (Showdown b2cb775; the Champions mod has no override for any of the seven)

- **Body Slam** `data/moves.ts:1585-1600`: 85 power, accuracy 100, `secondary: { chance: 30, status: 'par' }`, flags contact, protect, mirror, nonsky, metronome, minimize. The minimize flag matters only with the Minimize volatile, and Minimize is not marked (`src/data/support_manifest.c`), so no Pokemon can carry it. The generic STATUS_P secondary reads the row.
- **Razor Shell** `data/moves.ts:14761-14779`: 75 power, accuracy 95, slicing, `secondary: { chance: 50, boosts: { def: -1 } }`. The secondary reads the generic SECONDARY_TARGET boost. Sharpness (`data/abilities.ts:4174`, marked in G34) is the slicing pair.
- **Tickle** `data/moves.ts:19607-19625`: status, accuracy 100, `boosts: { atk: -1, def: -1 }`, reflectable. The primary boosts read the generic PRIMARY_TARGET row (as Charm, decision 0015 G39). Its reflectable flag puts it in the Magic Bounce list (tests/test_pool_g57.c), see below.
- **Heavy Slam** `data/moves.ts:8533-8563`: `basePowerCallback` with `pokemon.getWeight()` and `target.getWeight()` (`sim/pokemon.ts:685-688`: `Math.max(1, weighthg)`, in hectograms, so the ratio tests are integer comparisons: 5x, 4x, 3x, 2x give 120, 100, 80, 60, otherwise 40); its `onTryHit` is the Dynamax refusal (no Dynamax in the format). Weight modifiers: Float Stone (`onModifyWeight`, `data/items.ts:2177`), Autotomize (`data/moves.ts:878`), Heavy Metal and Light Metal (`data/abilities.ts`, unmodelled in the pool tables). None is marked and no pool member can carry one, so the forme's weight is the weight; the generator's fact check names the entry texts.
- **Hard Press** `data/moves.ts:8137-8150`: `basePowerCallback` of the target's current HP: `floor(floor((100 * (100 * floor(hp * 4096 / maxHP)) + 2048 - 1) / 4096) / 100) || 1`. The integer forms are exact (the products fit), checked against the pin's double arithmetic in `tests/test_pool_g86.c` (33 of 100 HP is 32).
- **Ice Spinner** `data/moves.ts:9417-9434`: `onAfterHit` and `onAfterSubDamage` call `this.field.clearTerrain()`. The AfterHit runs only while the user has HP (`sim/battle-actions.ts:1123`); the Substitute path runs it when the source has HP. There is no onTry, so with no terrain nothing happens (`clearTerrain` returns false, `sim/field.ts:159-167`).
- **Belly Drum** `data/moves.ts:1216-1234`: `onHit` returns false when `target.hp <= target.maxhp / 2`, `boosts.atk >= 6`, or `maxhp === 1` (the Shedinja clause); otherwise `directDamage(target.maxhp / 2)` and `boost({atk: 12})`. A false onHit with no `self` field prints `-fail|user` with `[still]` (`sim/battle-actions.ts:1301-1306`) and no Update (the Champions loop breaks before scripts.ts:537). `directDamage` (`sim/battle.ts:2207-2250`) is floored (`clampIntRange`) and prints `-damage` with no `[from]`; it does not set `hurtThisTurn`. `boost()` (`sim/battle.ts:2020-2088`) caps the change at +6 and prints for bellydrum a single `-setboost|X|atk|N|[from] move: Belly Drum` with the new stage N in place of `-boost` (`:2051-2052`).

## Decisions

1. **Rows.** Body Slam, Razor Shell and Tickle are data rows (no handler): the generator's generic secondary and boost parsers read them unchanged. Marked in the manifest only.
2. **Handlers** (generator ids 101 to 104 after Dragon Darts, UNMODELED moves to 105): `HEAVY_SLAM` (base power from the forme weights of the user and the target, `dfi_heavy_slam_power` in `src/combat/moves/families.h`), `HARD_PRESS` (`dfi_hard_press_power`), `ICE_SPINNER` (the terrain clear after a hit that landed or was absorbed, while the user stands; `dfi_clear_terrain`, the same event as Steel Roller's), `BELLY_DRUM` (`dfi_run_belly_drum`, the refusal by `dfi_fail_still`, the half-HP cost by `dfi_deal` with cause NONE, the boost by `dfi_boost` with `dfi_effect(MOVE, BELLYDRUM)`, then `dfi_status_hit_end`).
3. **Contrary holders of Belly Drum are refused** (`DUOFORGE_E_UNSUPPORTED`): the pin's ChangeBoost reverses the +12 (`sim/battle.ts:2032`); the clamp of `dfi_boost` assumes a rise. No Contrary holder is in the batch's teams.
4. **The boost event of Belly Drum.** The pin's `-setboost` is the same stat change as a `-boost` line, with the new stage in place of the change. The engine emits the existing BOOST event (16) of the change with cause MOVE and id2 = the move (`dfi_boost` tags a move boost that names its move; a plain move boost, Shell Smash, keeps cause NONE). No new public value. The converter (`tools/reference/trace_to_c.py`, `-setboost`) takes the change from the stage at the step's start, corrected by the Attack lines before it in the same step, and checks that the printed stage reaches the stage after the step with the Attack lines after it. Named refusals: `setboost` (not Belly Drum, another stat, or not an occupant), `setboost-stage`, `setboost-twice`, `setboost-change` (a change that is not positive), `setboost-clear` (a -clearallboost before it).
5. **Magic Bounce.** Tickle is reflectable. Its bounced run is the primary status boost path (`dfi_bounce_kind_ok`, `PRIMARY_TARGET`). tests/test_pool_g57.c gets one entry in the handled list and the marked count 24 to 25 (this branch's base; the batch's integrator combines it with C1's entries).
6. **Tail and public values.** None. No tail byte, no view bit, no volatile, no flags bit, no cause, no event kind.

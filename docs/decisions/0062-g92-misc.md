# 0062 - G92 misc: confusion moves, OHKO moves, Gigaton Hammer, Memento, Night Shade (step 5cu)

Status: **in progress** (H28b, lane A batch 6/7, step 5cu). The lead approved the design on 2026-10-11; this note records the implementation and its evidence as it lands.

## Scope

Marked (approved):

- CONFUSE: Confuse Ray, Swagger, Flatter, Teeter Dance (primary confusion; Swagger and Flatter boost first).
- OHKO: Fissure, Guillotine, Horn Drill (the OHKO path of Sheer Cold, step G64, generalised).
- Memento (selfdestruct ifHit), Night Shade (LEVEL_DAMAGE).
- Magic Bounce extension: a bounced Confuse Ray, Swagger or Flatter runs the CONFUSE handler (decided by the lead, 2026-10-11).

Dropped (approved by the lead, with the pin reason):

- Gigaton Hammer (cantusetwice; the lead's decision 2026-10-11, option b): its only Reg M-C learner is Tinkaton
  (`docs/research/expansion/data/legal_pool.json`), whose legal abilities are Mold Breaker, Own Tempo and Pickpocket. None is
  marked, so no legal pool team can contain it and no recorded battle can show its second use. Marking an ability is lane B's
  job. The generator leaves the flag unmodelled (the row is UNMODELED), so the move stays refused.
- The generic Encore override (Encore's onOverrideAction, data/moves.ts:4754-4758) was written for Gigaton Hammer's forced
  second use and is not in this step (the lead's decision of the same day).

- Snipe Shot: one learner in Reg M-C. The pin row (`data/moves.ts:17138-17151`) has `tracksTarget: true` (the move follows its original target when that foe is switched out, a redirect the request model does not carry). The Champions mod only changes its base power (`data/mods/champions/moves.ts:924-927`).
- Milk Drink: one learner in Reg M-C. The Champions mod sets `target: "adjacentAllyOrSelf"` (`data/mods/champions/moves.ts:648-651`), a target class the request model does not have.

Own Tempo and Safeguard stay refused (unmarked).

# M11 Behavior-Cloning Prior Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Learner v2 first learns human Reg M-C (and then M-B) play from the replay shards (`python -m duoforge_learn.bc`), and PPO starts from that network (`train.py --init`).

**Architecture:**
- The tracker folds the base-value features (Sand, Snow, Tox), so those games reach the encoder.
- `bc_data` turns shards into encoded, weighted and split arrays.
- `bc` trains model v2 on −log P(label set) plus the outcome value, and writes a format-2 checkpoint.
- `train.py --init` starts PPO from it. The parameters of the feature columns that are new beyond the checkpoint's mask are zeroed.

**Tech Stack:**
- Python 3.12, NumPy;
- JAX 0.11 and optax in WSL (`~/df-learn/bin/python`, CUDA);
- the DuoForge library through `python/duoforge`;
- pyarrow only in the replay venv, for the build of M-B shards.

**Spec:** `docs/superpowers/specs/2026-10-03-m11-bc-prior-design.md` (a695b9f, owner OK 2026-10-03).

## Global Constraints

- **AGENTS.md:**
  - correctness before optimization;
  - no hidden rule implementation in Python;
  - unsupported rules or capacities fail explicitly, never with a silent fallback;
  - determinism;
  - tests are never weakened;
  - performance claims need measurements.
- **Data rule:** the shards, `bc.npz`, the cache and every PPO checkpoint that descends from a BC network never go into the repository.
  - `bc.py` and `train.py --init` refuse outputs in any work tree (`duoforge_replay.dataset.refuse_repository`).
  - Tests use only our own fixtures (committed reference battles, `python/tests/data/replay/c12_real_cb_4.log`).
- **Machine:**
  - no GPU jobs and locally at most 2 × `-j4` from 22:00 to 07:00 (Learner v2's night run);
  - quiet windows are respected, and every long run is announced to the HauptSession;
  - never touch `~/df-build/night-*` or `~/df-build/learnv2`.
- **JAX tests** run in WSL: build `~/df-build/m11-bc` from this worktree with `-DDUOFORGE_LEARN_PYTHON=$HOME/df-learn/bin/python`, then `ctest -R 'duoforge.python.(learn_v2|bc)'`. Non-JAX tests run natively (`. build/env.sh && $PY -m unittest ...`).
- **Ownership:** `train.py`, `checkpoint.py` and `evaluate.py` are Learner v2's files. Changes there are announced to it, and it reviews them.
- **Pins:**
  - value coefficient 0.25;
  - rating weights: 1 at ≥1300, linear from 0.25 at 1000 to 1 at 1300, 0.25 below or unrated;
  - split: bucket 0 of 20, by the sha256 of the sorted sheet hash pair;
  - batch 1024, learning rate 3e-4, at most 20 epochs, patience 2.
- **Commits:**
  - end with `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`;
  - push only after `tools/ci/local_ci.sh --quick && git push`;
  - one PR (branch `chris/m11-bc`), with a review agent (fullstack-dev-kit:pr-reviewer, opus) at the end.

## Review Focus

1. **A dataset built under another library or with other tables than the run** must be refused, never encoded with shifted ids. Task 4: `test_dataset_of_another_library_is_refused`.
2. **A row whose label set is empty after `∩ pair_mask`** (the labeler and the provisional mask disagree) must raise, naming the replay and point. It must not train on −log 0. Task 5: `test_empty_label_set_raises`.
3. **A weather line the converter does not know under the now-folded Sand/Snow** (an old server's `-weather|Snow`) must stop by name, not fold wrongly. Task 1: `test_unknown_weather_form_still_stops`.
4. **An alias that the library does not find** (a typo or a new cosmetic forme) must stay a counted `name:` skip, not crash or map to the base. Task 2: `test_unknown_alias_stays_a_name_skip`.
5. **`--init` from a checkpoint whose mask is wider than the library's run-time mask** (a BC built on a newer library) must be refused. Task 7: `test_init_mask_wider_than_library_is_refused`.

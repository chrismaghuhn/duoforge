# M11 Bo1 Belief Source Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Champions games without open team sheets become a marked replay source (`bo1_belief`) whose sheets are sampled from a set belief, with validation (a) set recovery and (b) row difference measured offline.

**Architecture:** A per-member fact extractor reads what the log reveals (preview species, used moves, revealed item/ability). A set belief draws whole sets from a corpus of training-split sheets, conditioned on those facts, with back-off levels. The existing pipeline (`game.process`, the tracker, the prior, labels, the dataset writer) runs unchanged on the sampled sheets of both sides (option B). New source modes in `source`/`build`, new row fields, and a refusal in `bc_data` keep the source apart. Two CLI tools measure (a) and (b).

**Tech Stack:** Python 3.12, NumPy, pyarrow (spike venv) for parquet, the DuoForge shared library (POOL), Node + the pinned Showdown for stats; unittest with made-up logs.

**Spec:** `docs/superpowers/specs/2026-10-10-m11-bo1-belief-design.md` (approved: option B, split by player hash). Also `docs/superpowers/specs/2026-10-02-m11-replay-data-design.md` (the sheet pipeline).

## Global Constraints

- Replays, the corpus, datasets and reports with single games stay outside the repository (`dataset.refuse_repository`). Tests use made-up logs only; reports in the repository hold aggregates only.
- No player name or id in the repository or in any committed file; only the u64 hashes `game._hash8` already makes.
- Determinism: the same inputs, seed and draw give byte-identical outputs, independent of workers and processing order.
- Unsupported or ambiguous input fails explicitly: a counted `Skip` with its own reason, never a guess or a silent fallback; a broken invariant is a `ValueError` (an internal error of the build).
- Reg M-A is never built (`funnel.REG_MA`, #331).
- Heavy runs (builds over the HF data) only through `tools/ci/machine_lock.sh`, in the daytime; full test suites run on GitHub, not locally.
- No BC training runs: validation (c) needs the owner's OK and is not part of this plan.
- Split: a game is a test game when either player hash `h` has `h % 20 == 0`; otherwise a training game.
- Back-off: L0 a whole corpus set agrees with every fact; L1 item/ability from agreeing sets, moves = used moves + slots drawn from the species' move frequencies; `min_sets = 5`; fewer → skip.
- Legality redraws: at most 8 per side, then `skip:belief-illegal`.
- K samples per game: default 1.

## Review Focus

1. A member whose item changed hands (Trick, Switcheroo, Knock Off, Thief, Covet, Bestow) must not get the new item as its original item: facts stop collecting the item of both members at the first such line (test in Task 2).
2. Preview names and in-battle formes differ (a Mega shown by `|detailschange|`/`|-mega|`, a preview `-*` wildcard such as `Urshifu-*`): the member is matched by base forme, the stone becomes the item fact, a wildcard preview is resolved by the switch details or skips (`skip:belief-preview`) (tests in Task 2).
3. Moves are reported by nickname (`|move|p1a: Nick|…`): the nickname maps to its member through that side's switch details; a called move (`[from]` other than `lockedmove`) is no own move (test in Task 2).
4. The validation must never draw a game's own sheet: a game whose sheet hash is in the corpus raises `ValueError` (test in Task 4).
5. Words do not depend on order: the draw of (seed, replay, side, member, attempt, draw) is the same in any worker or member order (test in Task 3).

Rules the tests pin:

- Moves: `|move|POS|Move|…` of the member at POS. The member at POS follows `switch`/`drag`/`replace` details, mapped by base forme. Lines carrying `[from]` are skipped, except `[from]lockedmove`/`[from] lockedmove`. Struggle is skipped.
- Item, in order of the member's lines:

From the first Skill Swap, Entrainment, Worry Seed, Simple Beam, Doodle, Role Play or Mummy/Lingering Aroma line involving the member, nothing more.

### Task 3: The set corpus and the set belief

**Files:**
- Create: `python/duoforge_replay/corpus.py`, `python/duoforge_replay/setbelief.py`
- Test: `python/tests/test_replay_unit.py` (classes `CorpusTest`, `SetBeliefTest`)

**Interfaces:**
- Consumes: `source.units/read_unit`, `split.players_of`, `split.of_game`, `teams.unpack`, `data.canonical`, `game._hash8`, `facts.MemberFacts`, `prior.parse_paste`.
- Produces:
  - **`corpus.build(paths, format_prefix, registry_dir, out_path) -> dict`** writes JSON:
    - `{"version": 1, "format_prefix": [...], "split": "train", "min_sets": 5, "sources": [{"file", "bytes", "sha256"}], "registry": {"teams", "sha256"}, "sheet_hashes": [u64…], "sets": {species_key: [[item, ability, nature, [moves…], count], …]}}`;
    - `species_key = trace_to_c.key(data.canonical(species))`; names are kept as the sheet spells them.
    - It reads only games with exactly two sheets, of the training split.
    - Each distinct sheet hash counts once: a Bo3 team is one team.
    - It adds every `PP_` and `LL_` registry set, count 1.
    - The output is refused inside the repository.
  - **`corpus.load(path) -> Corpus`** with `.sets(species_key) -> list[tuple]`, `.sheet_hashes: frozenset`, `.sha256: str`.
  - **`setbelief.word(seed: int, replay_id: str, side: int, member: int, attempt: int, draw: int) -> int`** = `int.from_bytes(sha256(f"{seed}|{replay_id}|{side}|{member}|{attempt}|{draw}").digest()[:8], "little")`.
  - **`setbelief.SetBelief(corpus, min_sets=5)`** with **`.draw(member: MemberFacts, word: int) -> (dict, int)`**:
    - It returns a `teams.unpack`-shaped set (`name` = species, `evs` all 0, `level` 50) and its level (0 or 1).
    - Frequency-weighted pick: index `floor(word * total / 2**64)` over the cumulative counts in the corpus order.
    - L1 move fill: the same word drives a second pick, `sha256(word, slot)`, without replacement.
    - `Skip("skip:belief-unsupported <species>")` when the species has fewer than `min_sets` sets, or no set agrees on the item/ability facts.

    - A game whose players' sheets hash, from the dropped lines and passed in as `known_sheets`, is in `corpus.sheet_hashes` raises `ValueError` (Review Focus 4).

### Task 7: Validation tools (a) and (b)

**Files:**
- Create: `python/duoforge_replay/validate.py`
- Modify: `python/duoforge_replay/__main__.py` (subcommands `validate-sets`, `compare-rows`)
- Test: `python/tests/test_replay_unit.py` (class `ValidateTest`)

**Interfaces:**
- Consumes: Tasks 1 to 5, `prior.Prior.lookup`.
- Produces:
  - **`validate.set_recovery(true_sets, drawn_sets, member_facts, levels, prior) -> collections.Counter`**. Per member it counts:
    - `members`, and `members.level<L>`;
    - `moves.exact`;
    - `moves.unseen` and `moves.unseen_hit`: the true moves not in the facts, and how many of them the drawn set has;
    - `item.unrevealed` and `item.hit`;
    - `ability.unrevealed` and `ability.hit`;
    - `nature.hit`;
    - `prior_level.same`: the drawn set reaches the same prior key level as the true one.

    Ruling: the stat point L1 distance of the spec cannot be measured, because replays never show stat points (sheets neither). The prior level stands in.
  - **`validate.sets(paths, format_prefix, corpus, seed, out) -> dict`** runs over the test-split sheet games: facts with the sheets ignored, one draw, compared with the true sheets. It writes aggregates only, refused inside the repository.
  - **`validate.compare_rows(dir_sheet, dir_drop) -> dict`** matches rows by (replay_id, side, point) and reports:
    - `both`, `only_sheet`, `only_drop`;
    - per observation field group the share of rows whose bytes differ, with groups taken from `_layout.OBSERVATION` names: `own_members`, `foe_members`, `positions`, `header`;
    - the mean Jaccard of the factored-domain legal bits;
    - `label.same` and `label.overlap`.
  - CLI:
    - `validate-sets --source … --corpus FILE --format-prefix … --seed N --out FILE`;
    - `compare-rows SHEET_DIR DROP_DIR --out FILE`.

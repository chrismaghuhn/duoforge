5cv. **A spread move's Substitute hit reads the attacker's stages through the pin's activeTarget** (lane A batch 6, builder H18, branch chris/expansion-sub-fixes-2, decision 0015 entry 5cv; no new public value, event kind, cause or tail byte). The Unaware handler reads `this.activeTarget`: data/abilities.ts:5215-5228 zeroes the attacker's atk, def, spa and accuracy when the holder is the activeTarget and the attacker the activePokemon, and the defender's def, spd and evasion when the holder is the user and the defender the activeTarget. calculateStat runs that ModifyBoost with statUser (sim/pokemon.ts:560-581). For a Substitute hit of a spread move, activeTarget is not the hit target: sim/battle-actions.ts:693 sets it per target in hitStepAccuracy, in list order, and tryPrimaryHitEvent (:1138-1146) runs the Substitute's TryPrimaryHit with no assignment, so the value is the last target of the list that reached hitStepAccuracy (the list after invulnerability, TryHit, type and move immunity; the filter at :605 keeps truthy or 0 results). getSpreadDamage (:1154) sets it per target only after that loop. The list is built as allies then foes in position order (sim/pokemon.ts:724-735, :809-813), not by speed. Evidence on the pinned reference: fz_9003_167 step 12, list [Emboar, Hydreigon, Skeledirge], activeTarget Skeledirge (Unaware), so Armarouge's -2 is ignored for Hydreigon's Substitute (177, 265 with Flash Fire, damage 45, the Substitute breaks); fz_9003_168 step 9, list [Toxicroak, Appletun, Skeledirge], the same (damage 48, Appletun's Substitute breaks); fz_9003_72 step 9, Parabolic Charge, list [Milotic, Skeledirge, Kommo-o], activeTarget Kommo-o (no Unaware), so the -1 applies (122, damage 37, absorbed by Skeledirge's 44 HP). Engine: dfi_run_move_body computes act_target as the last hit flag before dfi_accuracy_targets; dfi_substitute_takes stores it in sub_active for its own damage calculation; dfi_get_damage reads the Unaware stages through it (pin_active; a single hit has pin_active = target, so single hits are unchanged). A multi-hit spread move is refused before that path (E_UNSUPPORTED, the hits-count check of dfi_run_move_body, since the pin's activeTarget is reset by the damage loop after hit one). Recorded POOL battles: sub3_lava_plume_spread_unaware_hydreigon_167, sub3_lava_plume_spread_unaware_appletun_168, sub3_parabolic_charge_spread_unaware_skeledirge_72 (pool 765).
